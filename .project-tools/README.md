# Herramientas heredadas del generador

Esta carpeta contiene referencias, plantillas y utilidades del entorno donde se inició el proyecto. Sus menciones de Grok, permisos de herramientas, secretos inyectados, dependencias preinstaladas y contratos del sandbox **no describen necesariamente el despliegue actual**.

Las guías vigentes de Prueba-724 están en la raíz: `README.md`, `AGENTS.md`, `SETUP_DATABASE.md`, `OPERATIONS.md`, `SECURITY.md`, `ARCHITECTURE.md` y `MULTIMEDIA.md`. Para versiones, instalación, permisos y configuración, consulta esas guías y el código actual.

Se conserva el material original como referencia de las utilidades de preview, identidad e instalación. No se publica como documentación de operación ni se deben copiar sus credenciales o supuestos al proyecto de Vercel. Los scripts activos de `scripts/` y su configuración son la evidencia del comportamiento real.
